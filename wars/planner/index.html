Guild SGL Wars Settings

Updating the guild list takes some time, as each API call can only retrieve up to 20 guilds, and then planning wars takes even longer, as each API call can retrieve the status of 1 guild at a time.
When updating the guild list or planning wars, the contents of this page will be replaced with a progress indicator.
Do not do anything with your API key during this process, as you will get ratelimited.

You must plan wars before viewing the list.
